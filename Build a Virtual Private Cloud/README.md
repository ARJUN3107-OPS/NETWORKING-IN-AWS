
# **Objective**

The goal of this project is to create a Virtual Private Cloud (VPC) in AWS, configure isolated subnets, set up routing for secure internet access, and apply security groups to manage traffic flow.

## **Steps**

1. **Create a VPC**: Define the IPv4 CIDR block for the VPC.
2. **Set up Subnets**: Create public and private subnets in different Availability Zones (AZs).
3. **Attach Internet Gateway**: Enable internet access for the public subnet by attaching an Internet Gateway to the VPC.
4. **Configure Route Tables**: Update route tables to ensure proper traffic flow between subnets and the internet.
5. **Security Groups**: Apply security groups to control access to the instances within the VPC.

## **Learnings**

- Gained hands-on experience in creating and configuring AWS VPCs, subnets, and routing.
- Learned how to set up and manage internet gateways for public access.
- Understood how to implement security groups for controlling access to network resources.
- Discovered the importance of planning and securing network traffic in cloud environments.
