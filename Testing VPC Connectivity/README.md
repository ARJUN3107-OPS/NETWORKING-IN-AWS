# **Objective**

The goal of this project is to test and troubleshoot VPC connectivity within AWS, ensuring proper communication between EC2 instances and the internet while maintaining security.

## **Steps**

1. **Test Connectivity**: Verify the ability to connect to public servers via SSH using EC2 Instance Connect.
2. **Ping Test**: Use the `ping` command to check connectivity between servers within the VPC.
3. **Troubleshooting**: Resolve issues like blocking ICMP traffic by updating security groups and ACL settings.
4. **Internet Connectivity**: Test internet access using `curl` to interact with web services and APIs.

## **Learnings**

- Gained experience in configuring security groups and route tables for proper network access.
- Learned how to troubleshoot connectivity issues in VPCs using ping and curl.
- Discovered the difference between basic connectivity testing (ping) and web service testing (curl).
- Understood the importance of correctly configuring firewalls and security groups to ensure connectivity.
