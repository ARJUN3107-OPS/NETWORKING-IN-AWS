# **Objective**

The goal of this project is to launch EC2 instances in a VPC, configure networking and security groups, and establish both public and private servers with secure access and communication.

## **Steps**

1. **Set up EC2 instances**: Launch public and private EC2 instances within the VPC.
2. **Configure direct VM access**: Set up SSH key pairs to enable secure access to the EC2 instances.
3. **Set security groups**: Configure security groups for public and private servers, ensuring restricted access between them.
4. **Use VPC resource map**: Utilize VPC resource maps to visualize network components and resources.
5. **Configure NAT Gateway**: Optionally, set up NAT Gateway for private instances to access the internet securely.

## **Learnings**

- Learned how to set up direct access to EC2 instances via SSH and RDP.
- Gained understanding of using security groups to restrict traffic between public and private servers.
- Discovered the importance of using VPC resource maps to visualize and manage VPC architecture.
- Experienced creating a VPC quickly using alternative methods and configuring necessary network resources.
