# **Networking in AWS**

This repository contains a series of projects focused on building, configuring, and managing networking solutions in Amazon Web Services (AWS). The projects cover essential aspects of VPC networking, traffic flow, security, and monitoring.

## **Projects Overview**

- **Build a Virtual Private Cloud (VPC)**: Setting up a basic VPC with subnets, route tables, and internet gateway.
- **Launching VPC Resources**: Creating and deploying resources like EC2 instances and RDS databases within a VPC.
- **Testing VPC Connectivity**: Verifying VPC networking functionality using different testing strategies.
- **VPC Endpoints**: Configuring private connections to AWS services using VPC endpoints.
- **VPC Monitoring with Flow Logs**: Implementing VPC flow logs for monitoring traffic in the network.
- **VPC Peering**: Establishing network connectivity between two VPCs using VPC Peering.
- **VPC Traffic Flow and Security**: Managing security with security groups, network ACLs, and traffic routing.

## **Skills Learned**

- **AWS VPC Configuration**: Setting up, configuring, and managing VPCs and related networking resources in AWS.
- **Network Security**: Configuring security groups, network ACLs, and IAM roles for secure network access.
- **VPC Peering and Connectivity**: Establishing and troubleshooting network connections between VPCs.
- **Private Networking**: Implementing VPC Endpoints for secure, private communication between AWS services.
- **Traffic Monitoring**: Utilizing VPC Flow Logs to monitor and analyze network traffic.
- **AWS EC2 & RDS Setup**: Deploying and managing EC2 instances and RDS databases within VPCs.
- **Troubleshooting AWS Networking**: Diagnosing and fixing common networking issues in AWS environments.
